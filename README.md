## 📖 Descripción

**AFI CAFE** es una aplicación web desarrollada para presentar el catálogo de productos de la empresa de forma moderna, rápida y adaptable a cualquier dispositivo.

Su objetivo es ofrecer una experiencia visual agradable para clientes y facilitar la administración del contenido.

---

- ☕ Catálogo de productos

## 🚀 Instalación

```bash
git clone https://github.com/aficafe/afi-cafe.git
```

Instalar dependencias

```bash
npm install
```

Ejecutar

```bash
npm run dev
```

Generar versión de producción

```bash
npm run build
```
